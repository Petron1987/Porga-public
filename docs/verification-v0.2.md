## 本轮已实现

| 能力 | 行为 |
|---|---|
| 检查点恢复 | 复用已完成的 Chief/Research/QA 成果，只重新执行未完成步骤 |
| 崩溃整理 | 显式 recover，不自动重复未知请求，OS 锁随进程退出释放 |
| 在线恢复授权 | 未完成的在线步骤需 allow-replay，原预算与未知预留继续生效 |
| 防重复 | 同一 request-key 与相同输入/配置返回原结果；冲突输入被拒绝 |
| 持久预算 | 每次调用事务预留/结算，重启不清零，同目录跨任务共享每日上限 |
| 取消 | 请求协作式停止；已发送请求仍可能计费，后续调用/工具/保存边界检查状态 |
| 完整性 | 审批与恢复前检查项目、全部成果哈希及已完成任务的关联 |
| 升级 | 加法迁移到 SQLite user_version=1，原 v0.1 内容保留并先生成备份 |
| 备份还原 | SQLite 一致性快照，校验备份，只允许还原到空目标目录 |
| 可读成果 | Markdown 报告与 JSON 导出；状态、健康检查与准备情况诊断 |
| 门禁回归 | 六个固定来源/引用/QA 案例，明确不代表真实模型质量 |
